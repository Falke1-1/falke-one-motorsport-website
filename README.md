# FALKE ONE MOTORSPORT - Official Website

Официальный сайт симрейсинг-команды FALKE ONE MOTORSPORT и инженерного бюро F1Performance.

## О проекте
Сайт создан для презентации команды, пилотов и гоночных сетапов. 
Включает эмблему команды, описание, фото болида, список пилотов и ссылки на соцсети.

## Технологии
- Python + Flet (Streamlit деплой)
- Адаптивный дизайн
- Темная гоночная тема
